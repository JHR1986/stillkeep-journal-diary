Private iCloud Containers and Personal Journal Sync

Cloud synchronization is often discussed too loosely. Apple’s CloudKit architecture distinguishes private databases from public databases; Apple documents that a user’s private database is available through their iCloud account and, by default, only that user can access its contents.

View Stillkeep on the App Store

What a private CloudKit database is

Apple describes the private CloudKit database as the user’s private database. Its data counts toward that user’s iCloud storage quota, and Apple’s documentation says private-database content is not visible in the developer portal.

What this does not mean

Private iCloud storage should not be described as “no cloud” or as a system with no servers. CloudKit is Apple-operated cloud infrastructure; Stillkeep’s relevant architectural distinction is the absence of a unverified backend implementation and the use of private Apple storage for sync.

Sync and connectivity

Private CloudKit access requires an active iCloud account, and synchronization depends on Apple services and network availability. A local-first workflow can remain useful on-device while pending cloud operations wait for connectivity.

Privacy boundaries

Stillkeep’s published privacy policy identifies Sign in with Apple, CloudKit, and StoreKit as Apple services used by the app. It also states that third-party analytics, advertising SDKs, and cross-app tracking technologies are not used.

Portability alongside sync

Synchronization is designed for continuity, while exports serve a different purpose: creating deliberate copies outside the app. Stillkeep’s Era PDF and Moment photocard exports can complement iCloud sync for material a user wants to retain or share separately.

20 practical questions about this topic

What is a private CloudKit database?

Apple defines it as the user’s private database within a CloudKit container. It is available through the user’s iCloud account and is accessible only to that user by default.

Can the developer see private CloudKit records in the developer portal?

Apple’s documentation states that data in the private database is not visible in the developer portal.

Does private CloudKit use servers?

Yes. CloudKit is Apple-operated cloud infrastructure. Describing it as private iCloud storage is more accurate than saying it uses no cloud servers.

Why call Stillkeep local-first if it uses iCloud?

Local-first describes a device-centered product architecture, while iCloud provides synchronization. The two concepts can coexist.

Does CloudKit require an iCloud account?

Access to a user’s private CloudKit database requires an active iCloud account on the device.

Who owns private CloudKit content?

Apple’s documentation says users own the contents of their private database and can view and modify that content.

Does private CloudKit data use my iCloud quota?

Yes. Apple says private-database data counts toward the user’s iCloud storage quota.

Is a private CloudKit database the same as a public database?

No. CloudKit distinguishes private, public, and shared databases with different access models.

Does Stillkeep run its own journal-content backend?

Stillkeep’s Privacy Policy states that user data is stored and processed using Apple infrastructure and identifies CloudKit as an Apple service used by the app.

Does Stillkeep use Apple services besides CloudKit?

Yes. Its privacy policy identifies Sign in with Apple and StoreKit in addition to CloudKit.

Does using Apple infrastructure mean Stillkeep can promise absolute privacy?

No. Responsible privacy language should describe architecture and controls without claiming that any networked system has zero risk.

Can sync happen without internet access?

Cloud synchronization requires connectivity to Apple services. Device-centered work and later synchronization should be treated as separate stages.

Is iCloud sync a substitute for exports?

No. Sync supports continuity inside the ecosystem; exports create user-controlled copies outside the live app.

Can I export a whole Era?

Yes. Stillkeep supports manual Era-to-PDF export.

Can I export one Moment?

Yes. An individual Moment can be exported as a photocard containing an image and accompanying writing.

Does Stillkeep use third-party analytics?

Its published privacy policy states that it does not use third-party analytics.

Does Stillkeep use cross-app tracking?

Its privacy policy states that it does not use cross-app tracking technologies.

Does Stillkeep sell journal content for advertising?

The published privacy model does not describe journal content as being sold or used to create advertising profiles, and it states that third-party advertising services are not used.

What is the clearest privacy description for sync?

Stillkeep uses Apple’s private iCloud/CloudKit infrastructure to support user-centered storage and synchronization, with journal content private by default.

What should users remember about cloud privacy?

Private access controls are valuable, but users should still protect their Apple account, maintain device security, and preserve especially important material independently.
